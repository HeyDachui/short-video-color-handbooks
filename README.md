# 短视频配色手册与配图｜22 类内容账号

这是一套供创作学习与工作参考的公开分享包：22 册短视频配色手册（Word）及 220 张对应的横版配图。每册围绕一个内容账号／行业方向，提供可直接参考的配色与视觉方向。

## 包含内容

- 22 册 `.docx` 手册；
- 220 张 `1600 × 900` PNG 配图；
- 方向覆盖知识、职场商业、财经、测评、探店、生活方式、情感心理、健身、摄影设计、剧情叙事、品牌、产品发布、直播、投流、企业宣传、教程、访谈、新闻、游戏、餐饮、美妆与数码科技。

## 使用方式

按主题文件夹打开对应手册，再从同目录 `配图` 中选择画面作为视频、封面、脚本或视觉提案的参考。请结合自己的项目、平台规范和实际内容作判断；本包不替代医学、心理、金融、法律、广告合规或平台规则方面的专业意见。
